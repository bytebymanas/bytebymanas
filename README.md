### 🧠 Yukti AI
**Socratic DSA mentor, fully local**

Guides you to the answer with questions instead of handing it over.

- 3-layer context pipeline: rolling summary + 4-turn window + current message
- Cross-session memory via async behavioral snapshots in SQLite
- Cloud GPU inference over ngrok with local Ollama fallback

`FastAPI` `Ollama` `Qwen2.5` `SQLite`

<td width="50%" valign="top">

### 📰 Sift AI
**Agentic news curation pipeline**

Reads 15-20+ articles a day and keeps only what's worth your time.

- Multi-agent CrewAI flow scoring substance, credibility and learning value
- Local Qwen2.5 inference with retry/fallback orchestration
- RSS + REST ingestion, dedup, auto PDF digest over SMTP

`CrewAI` `Ollama` `WeasyPrint`

</td>

**Deep learning text classifier**

Separates fake from legitimate news using sequence models.

- RNN/LSTM with Word2Vec embeddings and Byte-Pair Encoding
- Accuracy lifted from **88% to 94.6%** by tuning sequence length and embedding size

`TensorFlow` `LSTM` `Word2Vec` `NLP`
